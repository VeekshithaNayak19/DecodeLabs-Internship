# Full Stack Development Project 1 – Student Portfolio Website

##  Project Overview

The Student Portfolio Website is a personal portfolio developed as part of my Full Stack Development learning journey. It introduces me as an MCA student and aspiring Full-Stack Developer and showcases my technical skills, academic projects, and contact information.

The website is designed with a clean and user-friendly layout, allowing visitors to explore different sections through the navigation menu.

##  Objectives

- Build a personal portfolio website using HTML, CSS, and JavaScript.
- Create a structured and user-friendly website.
- Showcase technical skills and academic projects.
- Implement interactive navigation.
- Develop a contact form with input validation and submission feedback.
- Practise frontend web development concepts.

## 🛠️ Technologies Used

- **HTML5** – Structures the website content.
- **CSS3** – Styles the website and layouts.
- **JavaScript (ES6+)** – Implements interactive features and form handling.
- **FormSubmit** – Handles contact form submissions through a third-party service.
- **GitHub** – Stores and manages the project repository.

##  Features

- **Home Section:** Introduces me as an MCA student and aspiring Full-Stack Developer.
- **About Me:** Describes my interests in software and web development.
- **Skills Section:** Displays HTML5, CSS3, JavaScript, DBMS & SQL, Machine Learning, and Python.
- **Projects Section:** Showcases academic projects, including a Tours and Travel Website and a Canteen Management System.
- **Interactive Navigation:** Allows visitors to navigate between Home, About, Skills, Projects, and Contact sections.
- **Mobile Navigation Toggle:** Opens and closes the navigation menu and updates its accessibility attributes.
- **Automatic Copyright Year:** Displays the current year in the footer using JavaScript.
- **Contact Form:** Collects the visitor's name, email address, and message.
- **Form Validation:** Checks that all required contact fields are completed.
- **Submission Status Messages:** Displays feedback while sending a message and reports success or failure.
- **Form Reset:** Clears the form after a successful submission.

##  How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Ensure `index.html`, `style.css`, and `script.js` are present in the same folder.
4. Open `index.html` in a web browser.
5. Explore the portfolio sections using the navigation menu.

No additional software installation is required to open the static website.

**Note:** An internet connection is required for the contact form's third-party submission service. Successful email delivery depends on the FormSubmit configuration and email activation.
